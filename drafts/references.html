Personal portfolio inspiration

A few places to look around.

Collections to browse yourself, plus the individual pages behind the latest drafts. Start with Arche for minimal layouts or PersonalWebsites.org for a more personal, independent-web feel.

Collections

Arche — minimalist portfolios ↗

Start here for restrained typography, spacing, and personal developer/designer pages.

PersonalWebsites.org ↗

Personal homepages, portfolios, and blogs from people across many disciplines.

One Page Love — portfolios ↗

Screenshot-led collection of one-page portfolios; useful for comparing overall layouts.

512KB Club ↗

Lightweight websites, including many personal sites. Useful for simple, fast, mostly text-based ideas.

NowNowNow ↗

A directory of personal websites with /now pages. Useful for human, conversational introductions.

Siteinspire ↗

Broader design collection. Use its Portfolio, Minimal, Typographic, and Grid Layout categories.

UW CS Webring ↗

Student and alumni personal portfolios; the original reference collection for these drafts.
